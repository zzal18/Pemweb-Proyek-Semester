# AI Usage Log (Catatan Penggunaan AI)

Penggunaan Artificial Intelligence (AI) dalam proyek ini dimanfaatkan sebagai mitra diskusi dan pembantu teknis (*thought partner & troubleshooting*) dengan rincian berikut:

1. **Perancangan Struktur CSS**: AI digunakan untuk memberikan masukan struktur CSS berbasis Custom Properties dan layout Grid/Flexbox.
2. **Penyusunan Dokumentasi**: Membantu merumuskan catatan keputusan desain, pengujian aksesibilitas, dan template README yang terstruktur secara profesional.
3. **Git Troubleshooting**: Membimbing penanganan perbaikan riwayat commit (*git reset*, *git push --force*) dan pengelolaan branch pada repositori GitHub.
